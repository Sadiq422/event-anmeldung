# Die 90 besten Kinder- und Jugendbücher

Kuratierte Auswahl. Kriterien: Literaturpreise (Deutscher Jugendliteraturpreis, Newbery, Carnegie, Caldecott), jahrzehntelange Präsenz in Schul- und Bibliothekskanons, anhaltende Auflagen. Reihenfolge innerhalb einer Gruppe ist **kein** Ranking.
